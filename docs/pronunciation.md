# Word pronunciation

When the source language is English, double-click a recognized word in the translation result to open its word card.

The optional Free Dictionary API may return an IPA transcription and pronunciation audio links alongside its definitions and examples. DeskTranslate displays the phonetic transcription as text. When an approved audio link exists, the card shows **Open pronunciation audio**. Selecting it opens the HTTPS media URL in the system's default browser or media handler; DeskTranslate does not autoplay or download audio in the background.

Not every word has a pronunciation record. Dictionary availability is optional: a missing definition, phonetic transcription or audio link does not prevent ordinary translation or saving a word to Learning.

Only the selected English word is sent to the dictionary service. No screenshot or surrounding OCR text is included. Audio links are accepted only from the official dictionary API media host and its English pronunciation path. The external audio opens only after a separate user click.

Dictionary definitions, source URLs and license information continue to be shown when available. The public service and its content may be unavailable or incomplete.
